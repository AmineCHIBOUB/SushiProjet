=======================================================
  SUSHI PROJET — INSTALLATION
=======================================================

ETAPE 1 — Importer dans Eclipse
  Fichier > Import > Existing Projects into Workspace
  Selectionner le dossier SushiProjetFinal
  Eclipse detectera SushiAdmin et SushiApp

ETAPE 2 — Copier les donnees (IMPORTANT)
  Copier le dossier "sushi_data" (celui dans ce zip)
  directement dans le dossier webapps de Tomcat :

    C:\apache-tomcat-9.x\webapps\sushi_data\

  Ce dossier contient les fichiers pre-remplis :
    - sushis.txt     (15 sushis avec images)
    - recettes.txt   (5 recettes)
    - livraisons.txt (3 modes: sur place, a emporter, domicile)
    - commandes.txt  (cree automatiquement au 1er achat)
    - reservations.txt (cree automatiquement a la 1ere reservation)

ETAPE 3 — Lancer Tomcat
  SushiApp (site client) : http://localhost:8080/SushiApp/sushis
  SushiAdmin (admin)     : http://localhost:8080/SushiAdmin/sushis

=======================================================
  DESCRIPTION DU PROJET
=======================================================

  SushiApp : site client professionnel pour :
    - Consulter le menu avec images et filtres par categorie
    - Passer des commandes en ligne
    - Reserver une table (fonctionnalite innovante)
    - Voir ses commandes et reservations

  SushiAdmin : interface admin pour :
    - Gerer les sushis (ajout, modif, suppression avec images)
    - Gerer les recettes
    - Configurer les tarifs de livraison
    - Voir et gerer les commandes clients
    - Voir et gerer les reservations de table

  API REST : accessible via /SushiAdmin/api
    GET/POST/DELETE sur sushis, recettes, livraisons, commandes

=======================================================
  FONCTIONNALITES INNOVANTES
=======================================================
  1. Reservation de table en ligne (avec creneaux horaires)
  2. Filtre par categorie sur le menu (JavaScript dynamique)
  3. Design professionnel noir et or style restaurant haut de gamme

=======================================================
  TECHNOLOGIES UTILISEES
=======================================================
  - Java Servlets (javax.servlet) avec @WebServlet
  - JSP avec jsp:useBean, jsp:getProperty et JSTL c:forEach
  - Bootstrap 5.1.3 (CDN)
  - Persistance fichiers txt (pas de base de donnees)
  - Tomcat 9 + Eclipse
  - CSS personnalise (theme noir et or)
